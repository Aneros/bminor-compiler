# Examples

All `valid/*.bminor` files must exit 0 with `--check`; all `invalid/*.bminor`
files must exit 1 and still produce an AST/HTML when requested. These are
phase-one syntax tests, not compiled or executed programs.

```sh
./bminor --check examples/valid/showcase.bminor
./bminor --ast=text examples/valid/showcase.bminor
./bminor --tokens --json --trivia examples/valid/literals.bminor
./bminor --ansi examples/valid/showcase.bminor
./bminor --html examples/valid/showcase.bminor -o examples/showcase.html
./bminor --html examples/invalid/syntax_errors.bminor -o examples/errors.html
```

The final command intentionally exits 1 while writing the viewable HTML file.
`showcase.html` and `errors.html` are generated by the project binary and can be
opened directly in a browser with no server, JavaScript or external assets.

| Invalid example | Expected diagnostics |
| --- | --- |
| lexical_errors | L005, L001, L002, L007 and follow-on syntax diagnostics |
| syntax_errors | Three syntax errors; later print/return/global declarations survive |
| reserved_while | P003 explaining the reserved keyword |
| nested_function | P004 prohibiting nested definitions |
